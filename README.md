# 📊 HH.ru Vacancy Parser (Console Version)

Консольный парсер вакансий с сайта [hh.ru](https://hh.ru) для анализа востребованности технологий и уровня зарплат.

## 🎯 Что делает парсер

| Функция | Описание |
|---------|----------|
| Поиск вакансий | Python developer в Москве с указанными технологиями |
| Анализ зарплат | Расчёт средней зарплаты по найденным вакансиям |
| Сравнение технологий | Django, Flask, SQLAlchemy |
| Сохранение результатов | В JSON-файл (`data.json`) |

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| Python 3 | Язык программирования |
| requests | HTTP-запросы к HH API |
| json | Сохранение результатов |
